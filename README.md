# FinGuard AI

FinGuard AI is an autonomous finance agent that helps automate repetitive financial analysis and reporting.

## Project Goal

The agent will analyze Excel/CSV financial data, monitor budgets, detect anomalies, and generate executive-ready insights.

## Hackathon Track

Professional Agents

## Technologies

- Strands Agents SDK
- Python
- AWS
- Excel / CSV
- Power BI
